# Vuelos

App personal (PWA) con ofertas de vuelos desde Santiago para tu grupo: horarios, calendario de precios, equipaje, condiciones y comparación entre aerolíneas.

- La app (este repositorio) no contiene datos.
- Los datos viven en Google Drive, detrás de un Google Apps Script que solo responde con la clave del dueño.
- Se instala en Android desde Chrome: menú ⋮ → "Instalar app" o "Agregar a la pantalla principal".
